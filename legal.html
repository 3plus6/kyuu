tabukmaプライバシーポリシー

tabkma は、Chrome のサイドパネル上でブックマークと開いているタブを整理するための拡張機能です。

取得・利用する情報

本拡張機能は、機能提供のために以下の情報をブラウザ内で利用します。

  • ブックマークのタイトル、URL、フォルダ構成
  • 開いているタブのタイトル、URL
  • タブグループのタイトル、色、状態
  • 表示密度や文字サイズなどの設定情報

利用目的

これらの情報は、サイドパネル上でブックマークやタブを表示、並び替え、移動、整理するためにのみ利用します。

外部送信

本拡張機能は、取得した情報を外部サーバーへ送信しません。第三者に共有することもありません。

保存

表示密度や文字サイズなどの設定は、Chrome のローカルストレージに保存されます。ブックマークやタブの情報は、Chrome が提供する API を通じて表示・操作されます。

お問い合わせ

Chrome Web Store に表示されている連絡先メールアドレスまでご連絡ください。

tabero→Goo プライバシーポリシー

最終更新日: 2026年5月17日

tabero→Gooは、食べログの店舗ページからGoogle Mapsの口コミを小さな別ウィンドウで開くためのChrome拡張機能です。

収集する情報

tabero→Gooは、個人を特定できる情報、閲覧履歴、口コミ本文、口コミ点数、認証情報、支払い情報、位置情報を収集しません。

拡張機能は、ユーザーが開いている食べログの店舗ページ上に表示されている店舗名、住所または最寄り駅を読み取ります。これらの情報は、Google Maps検索URLを作成して小窓で開くためだけに使用します。

また、小窓を次回も同じ位置とサイズで開くため、ウィンドウの位置とサイズをユーザーのブラウザ内に保存します。

情報の保存

小窓の位置とサイズは、Chromeのローカルストレージに保存されます。この情報はユーザーのブラウザ内にのみ保存され、外部サーバーには送信されません。

店舗名、住所、最寄り駅は、Google Maps検索URLを作成するためにその場で使用されます。tabero→Gooはこれらの情報を独自の外部サーバーに保存しません。

第三者への提供

tabero→Gooは、ユーザーデータを販売、共有、転送しません。

Google Mapsを開く際、検索語句はGoogle MapsのURLとしてGoogleに渡されます。Google Maps上でのデータの取り扱いは、Googleのポリシーに従います。

リモートコード

tabero→Gooは、外部サーバーからJavaScript、CSS、その他の実行可能コードを読み込みません。拡張機能に含まれるコードのみで動作します。

データの利用目的

tabero→Gooは、ユーザーが選択した店舗のGoogle Maps口コミページを素早く開く目的にのみデータを使用します。広告、分析、信用判断、融資、第三者提供の目的では使用しません。

お問い合わせ

お問い合わせ先は、Chrome Web Storeのデベロッパー情報またはサポート欄をご確認ください。
