# kyuu website

個人事業の受け口、制作物一覧、アプリ・拡張機能の配布導線、支援導線、法務表記をまとめたGitHub Pages向け静的サイトです。

## 公開方法

1. GitHubでリポジトリを作成します。
2. このフォルダのファイルをpushします。
3. GitHubの `Settings` > `Pages` で公開元を設定します。
4. 最初は `https://<user>.github.io/<repo>/` で確認します。
5. 内容が固まったら独自ドメインのDNSをGitHub Pages向けに変更します。

## 主なページ

- `index.html`: トップページ、制作物一覧、支援導線
- `drifttt.html`: drifttt特設ページ
- `works.html`: 制作物一覧
- `support.html`: 支援メニュー、価格、提供条件
- `contact.html`: 問い合わせ先、サポート受付時間
- `legal.html`: 特定商取引法に基づく表記、プライバシーポリシー、共通利用規約、サービスごとのポリシー

## 公開前に差し替える項目

- Stripeに登録している事業者名とサイト上の事業者名が一致しているか確認
- driftttの正式説明、配布リンク、スクリーンショット
- 支援リンク
- 特定商取引法表記の運営責任者、所在地、販売条件
- サービスごとのロゴ、アイコン、OG画像

## 独自ドメインを使う場合

独自ドメインを設定する段階で、リポジトリ直下に `CNAME` ファイルを追加します。

例:

```text
example.com
```

DNS側ではGitHub Pages用のAレコードまたはCNAMEを設定します。
